01 · Instant links

Paste before it's finished.

The link lands on your clipboard the moment an upload starts. Anyone who opens it early gets a holding page that refreshes until the drop is ready.

0.0s

Capture

Hotkey, drag, done. Native macOS selection for screenshots, ScreenCaptureKit for video.

0.1s

Link copied

Paste into Slack, email or a ticket straight away. No waiting on a progress bar.

…

Upload lands

The "still uploading" page swaps itself for the drop. Prefer the old way? Turn instant links off.

02 · Features

Everything you'd reach for.

Screenshots, annotated mark-ups, screen recordings with a camera bubble, GIFs, notes and plain files, all from one icon in the menu bar.

Screenshot & annotate

Drag a region or press Space for a window, then mark it up.

  • Arrows, shapes, pen, highlighter, text
  • Pixelate, step numbers, emoji stamps
  • Undo/redo; upload, copy or save

Screen recording

Area, window or full screen, with a countdown and a control bar that never appears in the video.

  • Pause (paused time is cut), mute, delete
  • System audio + mic mixed to one track
  • Draggable round camera bubble

GIFs

Same capture flow as video, output as a looping GIF for docs, PRs and issue trackers.

Drop anything

Drag files or text onto the icon, upload the clipboard, or use the Finder Services menu.

  • Folders and multiple files zipped
  • URLs on the clipboard get shortened
  • Auto upload native ⌘⇧3/4/5 captures

Private by choice

Set defaults for new drops: public, password or private, self destruct timers and download permission.

  • Passwords hashed on the Mac
  • Plaintext stays in your Keychain

Chrome extension

Full-page captures of the tab you're on, including signed in pages, stitched like a scroll capture.

  • Captures inner scroll panels too
  • Pick an element or drag an area

04 · Storage

Your bucket. Your links.

Point Dropshot at any S3 compatible endpoint and a public base URL. Files live where you put them, served from your own domain, with no third party to go down, re-authenticate or change its pricing.

05 · Install

Up and running in minutes.

No signed release yet, so build it with Xcode. You'll need XcodeGen and macOS 15 or later.

~/dropshot
# clone and build the Mac app
$ git clone https://github.com/1stevengrant/dropshot
$ cd dropshot
$ xcodegen generate
$ xcodebuild -project Dropshot.xcodeproj \
    -scheme Dropshot -derivedDataPath build build
$ open build/Build/Products/Debug/Dropshot.app
  1. Settings opens on first launch. Under Storage, add endpoint, bucket, keys and public base URL.
  2. Hit Test Upload to confirm objects are publicly readable.
  3. Grant Screen Recording when macOS asks on your first capture.
~/dropshot/extension
# optional: the Chrome extension
$ cd extension
$ npm install
$ npm run build

# chrome://extensions → Developer mode
# → Load unpacked → extension/dist

# full page   ⌥⇧D
# area        ⌥⇧S  (or right-click)
